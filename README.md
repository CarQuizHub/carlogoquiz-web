# Car Logo Quiz - Frontend Worker

Frontend for [Car Logo Quiz](https://www.carlogoquiz.com), built with **Astro** + **Svelte** on **Cloudflare Workers**.

## 🛠 Tech Stack

- **Framework:** [Astro](https://astro.build/) (SSR + Static) + [Svelte 5](https://svelte.dev/) (Interactive Islands)
- **UI Library:** [DaisyUI](https://daisyui.com/) (Components and Themeing)
- **Runtime:** [Cloudflare Workers](https://developers.cloudflare.com/workers/)
- **Backend:** RPC via Service Bindings to [`carlogoquiz-api`](https://github.com/CarQuizHub/carlogoquiz-api)
